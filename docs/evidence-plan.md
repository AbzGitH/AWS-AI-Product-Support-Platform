# Project 5 Evidence Plan

Capture only meaningful proof that demonstrates the platform working end to end.

## Core Evidence

- Architecture / infrastructure deployed successfully
- Frontend accessible through the customer-facing URL
- API request successfully reaches backend logic
- DynamoDB read/write confirmed
- Amazon Bedrock returns an AI-assisted response
- Containerised component running successfully
- GitHub Actions workflow completes successfully
- CloudWatch logs and monitoring confirm application activity
- Final end-to-end customer interaction works through the live interface

## Evidence Standard

For each important screenshot, record:

- Title
- Screenshot filename
- What it shows
- What it proves

Prefer full-workspace screenshots where practical and avoid duplicate evidence.
